# fake-news-maker
カテゴリ別にランダム生成されるニュースアプリ風Webサイトです。
ボタンを押すことでニュースが生成されます。

<img width="959" height="497" alt="image" src="https://github.com/user-attachments/assets/d7a0abfb-0ec1-488a-9fe3-f36b259e2b25" />

・主な機能
- カテゴリ別に主語・動作・本文を自動生成します。
- 場所を47都道府県からランダムに選択します。
- カテゴリタブをクリックすると、そのカテゴリだけでニュース生成できます。再クリックで選択の解除も可能です。
  
・使用技術
- HTML / CSS / JavaScript
- DOM操作による動的コンテンツ生成

・制作の目的
未経験から学ぶ題材としてHTMLとCSSを選択し、学習したの内容の成果物として作成しました。
作成にあたって、Youtubeの動画(https://www.youtube.com/watch?v=LXUlkEBLayU&t=8397s)　で基礎的な知識を学んだ後、GitHub Copilotを用いてコード生成を行いサイトを完成させました。
